Standard 和 Professional 的差价，买的就是 PDF 输出和文本遮盖这两件事。打印预览、多页合一、拖拽调边距、删空白页、加水印页码、合并打印任务这些，Standard 全都有，日常办公里真正高频的功能一个没少。

有一个机制很多人不知道，买之前必须搞清楚。Standard 授权用户可以安装 Professional 版程序，用来试专业功能。Standard 本身的功能不受限制，正常打印也不会被塞东西进去。但只要你用 PDF 输出，导出的文件里会带一条横幅；用文本遮盖功能，打印出来同样带横幅。换句话说，拿 Standard 授权去白嫖 PDF 输出是行不通的，出来的文件在正式场合没法用。

Server 版的情况要单独说。它本身不是一个完整独立的授权，而是跟 Standard 或 Professional 授权配合工作的。从另一台电脑发到这台服务器上的打印任务，会带试用水印。也就是说，多人共享打印的环境不是买一份 Server 就完事，授权数量得跟实际使用的人和机器对上。

升级路径是通的。Standard 可以随时升到 Professional，Standard 和 Professional 也都能升到 Server，开发商官网写得明确。

## 常见问题

**买了 Standard，能不能用 Professional 的 PDF 输出？**

能装能用，但导出的 PDF 会带横幅，遮盖功能打印出来也带横幅。正式文件不能用。

**以后想升 Professional 怎么办？**

开发商支持随时从 Standard 升级到 Professional，也支持从这两个版本升到 Server。在数码荔枝这边具体怎么补差价，下单前问一下客服比较稳。

**终身授权包含后续大版本更新吗？**

平台条款把这些术语的定义交给了开发商，平台不对此作担保。买之前如果这一点对你很关键，直接问客服要一个明确答复。

**有没有免费试用？**

有。购买须知里写明大多数产品提供免费试用，建议先下载测试再购买。对不退款的数字商品来说，这一步不能省。

**Standard 和 Professional 除了 PDF 和遮盖，还有别的差别吗？**

主要就是这两项。打印预览、多页合一、页面重排、删除空白页、水印页码、合并打印任务、撤销重做、配置档这些，两个版本都有。
